# 우리 동네 산불 달력

산림청 「산림청_산불통계데이터」(공공데이터포털 파일데이터 15121380)의 산불 2,020건(2022년 1월 1일 ~ 2025년 9월 11일)을 시도, 시군구별로 묶어 달별, 시간대별, 요일별, 원인별 건수와 피해면적을 보여 주는 정적 웹페이지입니다.

- 공개 주소: https://didrod205.github.io/forest-fire-calendar/
- 원자료: fire_stats_20251110.csv (공공데이터포털에서 2026-11-17 내려받은 zip 안의 「산불발생통계(20251110).csv」, CP949 인코딩 그대로). 이용허락범위: 제한 없음(공공데이터포털 표기).
- 집계: `python3 build_data.py` → data.json, cause_mapping.tsv(원본 원인 글자와 이 사이트 묶음의 대응표).
- 원인 묶음은 원본 세부원인과 기타 칸 글자에 낱말 규칙을 적용해 이 사이트가 다시 나눈 것이며 산림청 공식 분류가 아닙니다.
- 글꼴: Pretendard(SIL Open Font License 1.1).
- 만든 곳: E:LAB STUDIO, 2026-11-17. 데이터 수집, 분석, 서비스 제작은 생성형 AI(Claude)로 했습니다.
